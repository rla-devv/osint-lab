# Dados sintéticos

Todo o conteúdo desta pasta é fictício. Os domínios usam o sufixo `.example`, reservado pela RFC 2606, e a organização e as pessoas citadas não existem.

Para importar os arquivos num projeto que já existe:

    osintlab importar <id_do_projeto> examples/dados_sinteticos

Para criar o projeto de demonstração completo, com proveniência e afirmações já registradas:

    osintlab exemplo
