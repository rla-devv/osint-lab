# Regras do repositório

- Identificação: sempre que um nome, autor ou titular for necessário, use apenas `rla-devv`
  (git: `rla-devv <rla-devv@users.noreply.github.com>`).
- Nunca incluir outros dados pessoais do proprietário (nome civil, e-mail, caminhos locais) em arquivos,
  commits, mensagens de commit ou metadados.
- Mensagens de commit sem linhas de coautoria ou links de sessão; manter o mínimo de metadados.
- Commits e envios vão direto para a branch `main`.
- Dados de exemplo devem ser sintéticos (domínios `.example`).
