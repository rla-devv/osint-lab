Acesso remoto (celular e outros computadores)

Login: {{ 'ativo' if acesso.ativo else 'desativado' }}{% if acesso.ativo %} · segundo fator: {{ 'ativo' if acesso.totp else 'não configurado' }} · exigido {{ 'em todos os acessos' if acesso.exigir_local else 'só em acessos remotos' }}{% endif %}{% if remoto %} · você está num acesso remoto{% endif %}

Para usar no celular sem expor o programa na internet: instale o Tailscale no computador e no celular, com a mesma conta, e rode no computador tailscale serve --bg 8765.

Passo a passo
  1. Instale o Tailscale (tailscale.com/download) no computador e no celular e entre com a mesma conta.
  2. Aqui, crie a senha de acesso e ative o segundo fator.
  3. Marque "Continuar rodando em segundo plano" e, se quiser, "Iniciar com o Windows".
  4. No Prompt de Comando do computador: tailscale serve --bg 8765. Aceite ativar HTTPS e MagicDNS se for pedido; o comando mostra o endereço https://….ts.net.
  5. No celular, com o Tailscale ativo, abra esse endereço e entre com a senha e o código.
  6. Desative a suspensão do Windows quando ligado na tomada: computador suspenso não responde.

Nada fica exposto na internet nem se abre porta no roteador. 5 tentativas erradas bloqueiam o aparelho por 5 minutos. "Origem não permitida": use exatamente o endereço mostrado pelo Tailscale. Para desfazer: tailscale serve reset.
